# Corrections for known Stanza lemma errors, applied in 03_remove_boilerplate.py
#
# Stanza guesses lemmas for words it has not seen in training, and some guesses are truncated
# ('kompetens' -> 'kompet'). This list corrects those known errors; it does not replace the
# lemmatizer.
#
# Format: one pair per line, the wrong lemma then the correct lemma, separated by whitespace.
# A leading '*' on the wrong lemma also corrects it at the end of a compound
# ('*kompet kompetens': gymnasiekompet -> gymnasiekompetens, it-kompet -> it-kompetens).
# Only use '*' after checking the compounds: 'anslagen' must not get it ('sammanslagen').
# After editing, re-run steps 03-05 (no need to re-run Stanza).
